Customer Churn Analysis Using Power BI

📌 Project Overview

Customer Churn Analysis is a data analytics project developed using Microsoft Power BI. The project analyzes customer data to understand churn behavior, identify patterns and discover factors that influence customer retention.

🎯 Project Objectives

- Analyze customer churn and retention rates.
- Understand customer demographics and behavior.
- Identify factors contributing to customer churn.
- Generate meaningful business insights through visualizations.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning and Transformation
- Data Visualization

📊 Dashboard Features

- KPI Cards for important business metrics.
- Customer demographics analysis.
- Churn analysis across different categories.
- Interactive charts and visualizations.
- Filters and slicers for detailed analysis

💡 Key Insights

The dashboard helps identify customer churn patterns, understand customer segments and analyze factors affecting customer retention.

📝 Conclusion

This project demonstrates the use of Power BI to transform raw customer data into meaningful visual insights and support data-driven business decisions.
